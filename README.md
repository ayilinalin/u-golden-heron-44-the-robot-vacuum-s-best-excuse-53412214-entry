One funny line for make.fun's "The Robot Vacuum's Best Excuse" bounty: the

140 characters. The program writes the line to `/output/entry.txt`.

## The line

## Run it

```sh
python3 main.py
```

The output directory follows `$MAKEFUN_OUTPUT_DIR` (default `/output`),

## Why this line

The judge is a tired homeowner comparing excuses pair by pair. The line
speaks as the vacuum itself, stays inside its own world — bumper, map,
battery — and turns at the end: the missed corner is not laziness, it is
a structural decision the battery has officially approved.
